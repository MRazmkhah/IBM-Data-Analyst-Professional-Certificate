# Python Project for Data Science

This course focuses on applying Python skills to a real-world data science project involving stock market analysis and dashboard creation.

### Key Topics Covered
- Extracting stock data using web scraping and Python libraries (yfinance)  
- Cleaning and analyzing historical stock and revenue data  
- Using Pandas for data manipulation  
- Creating visualizations and building a dashboard  

### Final Project
Developed a dashboard analyzing historical stock prices and revenue data to identify trends and support data-driven insights.

### Key Skills
- Web Scraping  
- Data Collection  
- Pandas  
- Data Visualization  
- Dashboard Development  
- Financial Data Analysis
