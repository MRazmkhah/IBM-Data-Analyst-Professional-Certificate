# Course 1 — Introduction to Data Analytics  

This course provides a foundational overview of the data analytics field, the data ecosystem, and the core steps involved in the analytics workflow.

### 🔍 What I Learned
- What data analytics is and how it is used  
- Key roles in the data ecosystem (Data Analyst, Data Scientist, BI Analyst, Data Engineer)  
- Types of data structures, formats, and repositories  
- The full data analysis process: collecting → wrangling → mining → visualizing
