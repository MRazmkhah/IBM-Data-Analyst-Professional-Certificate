# Databases and SQL for Data Science with Python

This course focuses on using SQL to analyze relational databases and integrating SQL with Python for data analysis.

### Key Topics Covered
- Writing SQL queries (SELECT, INSERT, UPDATE, DELETE)  
- Using WHERE, COUNT, DISTINCT, LIMIT  
- Creating and managing relational tables (DDL & DML)  
- Working with JOINs, subqueries, grouping, and sorting  
- Using built-in SQL functions  
- Connecting Python to databases using SQLite and SQL magic  

### Final Project
Analyzed real-world Chicago city datasets using SQL queries in SQLite.  
Translated business questions into SQL queries and interpreted the results for data-driven insights.

### Key Skills
- SQL  
- Relational Databases  
- Data Querying  
- JOINs & Subqueries  
- Database Functions  
- SQLite with Python  
- Data Analysis
