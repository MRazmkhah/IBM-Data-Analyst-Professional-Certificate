# 📍 About the Professional Certificate  

The IBM Data Analyst Professional Certificate provides end-to-end training for **entry-level data analyst roles**, covering the full analytics workflow:

- Collecting and importing structured data  
- Cleaning, transforming, wrangling, and organizing datasets  
- Querying relational databases with SQL  
- Analyzing data using Python (Pandas, NumPy, SciPy)  
- Creating charts and dashboards (Excel, Cognos Analytics, Plotly, Dash)  
- Working with real-world data from APIs and web scraping  
- Applying Generative AI to enhance data preparation, analysis, and storytelling  

Learners work with real datasets, real scenarios, and applied business cases to build job-ready, practical data analytics skills.
