# Course 8 — Data Visualization with Python

This folder contains my work for **Course 8: Data Visualization with Python**, part of the IBM Data Analyst Professional Certificate.  
The course focuses on creating effective visualizations using **Matplotlib**, **Seaborn**, **Folium**, **Plotly**, and **Dash**.

## 📊 Course Overview
In this course, I learned how to:
- Create standard visualizations (line, area, bar, scatter, histograms, pie, box).
- Build advanced visuals such as **waffle charts**, **word clouds**, and **regression plots**.
- Work with **geospatial data** using Folium and create **markers** and **choropleth maps**.
- Build **interactive dashboards** using Plotly and Dash.
- Apply data storytelling principles to present insights clearly.
