# Data Analysis with Python

This course focuses on end-to-end data analysis in Python, from data cleaning and preprocessing to exploratory data analysis (EDA) and building predictive models.

### What I Learned
- Importing and exporting datasets (CSV, Excel, etc.) into Pandas DataFrames  
- Cleaning and preparing data: handling missing values, formatting, normalization, and binning  
- Exploratory Data Analysis (EDA): descriptive statistics, grouping, and visualizations  
- Correlation analysis and basic statistical methods for understanding relationships  
- Building and evaluating regression models (linear and polynomial) using scikit-learn  
- Model evaluation and refinement using metrics like R² and MSE, plus regularization (Ridge)

### Final Project – House Sales in King County, USA

Applied the complete data analysis workflow on a real housing dataset:

- Cleaned and prepared house sales data for analysis  
- Performed EDA and visualized relationships between features and price  
- Built and evaluated regression models to predict house prices based on key property features  

### Tools & Libraries
- Python  
- Pandas, NumPy  
- Matplotlib, Seaborn  
- Scikit-learn  

### Key Skills
Data Cleaning • EDA • Data Visualization • Regression Modeling • Model Evaluation • Predictive Analytics
