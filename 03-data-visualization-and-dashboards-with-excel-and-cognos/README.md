# Data Visualization and Dashboards with Excel and Cognos

This course focuses on transforming business data into meaningful visualizations and interactive dashboards using Excel and IBM Cognos Analytics.

### Key Skills
- Creating bar, line, and column charts in Excel  
- Using pivot tables for data aggregation  
- Analyzing sales and profit trends  
- Building interactive dashboards in Cognos Analytics  

### Final Assignment
Analyzed car sales and profit data for multiple dealers and presented insights using Excel visualizations and a two-page dashboard (Sales & Service).
