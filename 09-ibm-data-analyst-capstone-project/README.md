# IBM Data Analyst Capstone Project

This folder contains my final capstone project for the **IBM Data Analyst Professional Certificate**.

## 📌 Overview
In this capstone, I applied the complete data analysis workflow using the **Stack Overflow Developer Survey** dataset, including:

- Data collection (APIs & web scraping)  
- Data wrangling & cleaning  
- Exploratory data analysis  
- Visualization (Matplotlib, Seaborn)  
- Dashboard creation (Cognos / Looker Studio)  
- Final presentation of insights

## 🎯 Deliverables
- **Final Presentation (PDF)** summarizing key findings  
- Additional analysis files and scripts (to be added later)

## 🧠 Skills Demonstrated
- API & web scraping  
- Data wrangling  
- EDA & visualization  
- Dashboard design  
- Analytical storytelling and reporting  

This capstone brings together all major skills from the full IBM Data Analyst program.
